# 知識点一覧（var・io・cond・col）

教材を作るときに見る一覧です。担当の知識点の行を、AI への依頼文にそのまま貼り付けてください。

## 使ってよい文法のルール

学生は **var → io → cond → col** の順に学びます。各トピックの中は番号の順に学びます。

- 使ってよいのは、**その知識点より前に習う内容**と、その知識点自身の内容だけです。
  - 例：`cond_02` の教材では、var・io のすべてと `cond_01`・`cond_02` を使ってよい。`cond_03`（and・or・not）や col（リスト・辞書）は使わない。
- 次の文法は、4つのトピックの**どこでも使いません**（後で習う内容です）。
  - `for`・`while`（繰り返し）
  - `def`・`return`（関数）
  - `import`、`try`/`except`、`lambda`、内包表記
- **例外**：`print(値)` の基本的な形は、var の最初から使ってよい（結果を表示するため）。`sep`・`end`・f 文字列は io で習うので、それより前では使わない。

この結果、4つのトピックの教材には次の制約があります。

- コード問題は **stdio 方式**（入力して出力する）だけを使う。function 方式は `def` が必要なので使えない。
- `input()` は io_02 から使える。var のコード問題は入力のない短いプログラムになるので、var では選択問題を中心にする。
- 繰り返しがないので、コード例も問題も「上から順に1回だけ実行される」短いプログラムにする。

## var：変数とデータ型

| ID | タイトル | 教えること | 注意 |
| --- | --- | --- | --- |
| var_01 | 変数と代入 | `=` による代入、再代入、変数名のつけ方 | `=` は「等しい」ではなく「代入」 |
| var_02 | 数値型（int・float）と算術演算 | `+ - * / // % **`、int と float | `/` の結果は常に float。べき乗は `**`（`^` ではない） |
| var_03 | 文字列の基本（連結・繰り返し・len） | 文字列の `+`・`*`、`len()` | 文字列と数値は `+` で連結できない（型変換は var_05） |
| var_04 | bool と比較演算 | `True`/`False`、`== != < > <= >=` | `=` と `==` の違い |
| var_05 | 型変換（int・float・str） | `int()`・`float()`・`str()`・`type()` | `int('3.5')` はエラーになる |
| var_06 | 複合代入演算子（+= など） | `+= -= *= /=` | `x += 1` は `x = x + 1` と同じ |
| var_07 | 文字列のインデックスとスライス | `s[0]`、`s[-1]`、`s[1:4]` | 0 から数える。スライスは終わりの位置を含まない |
| var_08 | 文字列メソッド | `split`・`join`・`replace`・`upper`・`lower`・`strip` | `split` の結果はリスト（col で習う）なので、`len()` を取る、`join` に渡す程度にとどめる |

## io：入出力

| ID | タイトル | 教えること | 注意 |
| --- | --- | --- | --- |
| io_01 | print の基本 | 複数の値の表示、`sep`、`end` | |
| io_02 | input（入力は常に文字列） | `input()`、プロンプト文字列 | 数字を入力しても文字列（`'3' + '4'` は `'34'`） |
| io_03 | 入力値を数値に変換する | `int(input())`、`float(input())` | 変換し忘れると計算できない、または文字列の連結になる |
| io_04 | f 文字列による整形出力 | `f'{x}'`、`{x:.2f}` などの書式指定 | |
| io_05 | 1行の複数の値を読む | `a, b = map(int, input().split())` | リストやタプルの説明はしない（col で習う）。この形だけを使う |

## cond：条件分岐

| ID | タイトル | 教えること | 注意 |
| --- | --- | --- | --- |
| cond_01 | if 文 | `if 条件:`、インデント | 条件の後の `:` とインデントを忘れやすい |
| cond_02 | else と elif | `else`、`elif`、条件を書く順番 | **見本あり**（下記）。上から順に調べ、最初に True になったところだけ実行される |
| cond_03 | 論理演算（and・or・not） | `and`・`or`・`not`、`0 <= x < 10` | `x == 1 or 2` のような誤り |
| cond_04 | 条件分岐のネスト | `if` の中の `if` | `and` で書き換えられる場合との比較 |

## col：コレクション

| ID | タイトル | 教えること | 注意 |
| --- | --- | --- | --- |
| col_01 | リストの作成とインデックス | `[1, 2, 3]`、`a[0]`、`a[-1]`、要素の書き換え | 範囲外のインデックスはエラー（IndexError） |
| col_02 | リストの操作 | `append`・`remove`・`pop`・`len` | `remove` は値を指定、`pop` は位置を指定 |
| col_03 | リストのスライス | `a[1:3]`、`a[:2]`、`a[::-1]` | 文字列のスライス（var_07）と同じ規則 |
| col_04 | 組み込み関数と in | `sum`・`max`・`min`・`sorted`、`in`・`not in` | `sorted` は新しいリストを返す（元のリストは変わらない） |
| col_05 | タプルとアンパック | `(1, 2)`、`a, b = t`、`a, b = b, a` | タプルは変更できない |
| col_06 | 辞書の作成・参照・更新 | `{'a': 1}`、`d['a']`、追加・更新 | ないキーを参照するとエラー（KeyError） |
| col_07 | 辞書のメソッド | `keys`・`values`・`items`・`get`、`キー in d` | 繰り返しは使えないので、`get` の既定値、`in` による確認、`list(d.keys())` の表示などにとどめる |
| col_08 | 集合 | `{1, 2}`、`set()`、`add`、`\|`・`&`・`-`（和・積・差）、重複の除去 | 空の集合は `{}` ではなく `set()` |
| col_09 | 2次元リスト | `m[i][j]`、行の取り出し | 繰り返しは使えないので、小さな固定の例で扱う |
